# BooksCollector

## Описание проекта

BooksCollector — приложение для работы с коллекцией книг.

Приложение позволяет:
- Добавлять новые книги.
- Устанавливать жанры книгам.
- Получать жанр книги по названию.
- Получать список книг определённого жанра.
- Получать список книг, подходящих детям.
- Добавлять книги в избранное.
- Удалять книги из избранного.

## Тестирование

Для тестирования приложения используется библиотека pytest.

В проекте реализовано 9 тестовых методов.

### Проверяемые методы

1. `add_new_book` — добавление книг, проверка длины названия и повторного добавления.
2. `set_book_genre` — установка корректного жанра и обработка некорректных данных.
3. `get_book_genre` — получение жанра книги.
4. `get_books_with_specific_genre` — получение книг по определённому жанру.
5. `get_books_genre` — получение словаря книг и жанров.
6. `get_books_for_children` — получение книг, подходящих детям.
7. `add_book_in_favorites` — добавление книг в избранное и проверка повторного добавления.
8. `delete_book_from_favorites` — удаление книги из избранного.
9. `get_list_of_favorites_books` — получение списка избранных книг.

Для сокращения повторяющегося кода используется параметризация `pytest.mark.parametrize`.

## Запуск тестов

Для запуска тестов необходимо установить pytest:

```bash
pip install pytest
```

Запустить тесты можно командой:

```bash
py -m pytest -v tests.py
```
